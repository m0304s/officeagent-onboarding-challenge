## 신규 확정 사실 (환경)

- **`Bash` 도구는 작업 디렉터리 밖 파일의 읽기를 차단합니다.** `head -c 400 ~/.claude/projects/.../*.jsonl`이 *"may only read the beginning of files from the allowed working directories"*로 거부됐습니다. `SKILL.md`가 세션 양 끝 시각을 뽑는 수단으로 적어 둔 `head`/`tail` 경로가 이 호스트에서는 **막혀 있습니다.** 반면 `Grep`·`Glob`은 같은 경로에 그대로 닿으므로, 시각은 `Grep(count)` → `Grep(offset: N-1, head_limit: 1)` 로 뽑습니다.
- **한 `Bash` 호출에 명령을 둘 이상 넣으면 승인 게이트가 부분만 지목하고 호출 전체를 거부합니다** — *"This Bash command contains multiple operations. The following part requires approval: …"*. 통과하는 명령까지 함께 죽으므로, 독립 명령은 **한 호출에 하나씩** 넣고 대신 여러 호출을 한 메시지에 병렬로 보냅니다.
- **`Grep(-o)`은 캡처 폭을 좁혀도 원본 줄이 매우 길면 `[Omitted long matching line]`로 통째로 생략합니다.** `AskUserQuestion` 입력처럼 긴 JSON은 `"name":"AskUserQuestion","input":\{.{0,900}` 같은 넓은 패턴으로는 아무것도 못 얻고, `"question":"[^"]{0,220}`·`"label":"[^"]{0,90}` 처럼 **짧은 키 단위로 나눠** 뽑아야 나옵니다.
- **셸 승인 게이트는 직전 회차와 같습니다** — `git log`·`git show`·`git status`·`git diff`·`grep -c`·`date` 단독은 통과, `command -v python3 jq`·`py.exe -3 -c`는 거부입니다.
